## 文件职责

- `data/master/topic_detail.csv`：用户提供的中老年主题明细总表，保留原始字段。
- `data/master/hot_topics.csv`：可用于检索和选题的统一主库。总表按原主题 ID 汇总，并补入 2026-09-03 之后的旧题库新增记录。
- `data/master/mother_topics.csv`：按母题汇总出现次数、主题数、最近日期和最高热度。
- `data/output/中老年主题分析.xlsx`：用户提供的总表分析工作簿，原样保留供查看。

## 去重规则

- 总表按 `主题ID` 汇总，保留首次日期、最近日期、出现次数和最高热度。
- 文章链接作为文章级唯一标识。
- 标题相同但链接不同的记录不自动删除，标记为“疑似重复标题：保留并人工复核”。
- 同一主题 ID 多次出现时，保留为一个主库主题，并累计出现次数。

## 每日更新流程

1. 将当天榜单放入 `data/raw/`，或更新用户维护的总表。
2. 先更新 `topic_detail.csv`，再按主题 ID 和链接更新 `hot_topics.csv`。
3. 更新 `mother_topics.csv`，检查新增、重复和日期覆盖。
4. 如果当天有新榜单，再生成当天选题；没有当天数据时，不把历史最新日期误写成今天。
5. 提交并推送 GitHub。
