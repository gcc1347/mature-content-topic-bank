# 熟龄爆款选题 Skill v1.0

## 目标

从当日热点中筛出适合“50岁以后”和“女人的下半场”系列的选题，同时利用历史题目库验证母题是否被反复关注。

## 输入

- `data/raw/` 中当天榜单文件。
- `data/master/hot_topics.csv` 主数据。
- `data/master/mother_topics.csv` 母题库。
- 用户当天已经发布或计划发布的选题，若有则用于防重复。

## 固定处理顺序

1. 读取当天榜单，保留标题、描述、热度、发布时间、链接、缩略图和来源文件。
2. 以链接、标题执行去重。重复上榜不删除历史信息，累计出现次数并保留最高热度。
3. 给新增题目补充系列、一级主题、二级主题、年龄、人群性别倾向、情绪、需求、标题骨架和母题。
4. 更新母题库的出现次数、最近日期、最高热度和当前等级。
5. 计算四个维度：热点强度、历史验证度、账号适配度、新鲜度。
6. 输出 1 个首选、2 个备选，并说明为什么今天选它。

## 默认评分

- 热点强度：当天热度与榜单位置。
- 历史验证度：同一母题的出现次数、覆盖日期和最高热度。
- 账号适配度：是否能自然落入熟龄生活、养老、家庭边界、女性年龄与自我价值等主题。
- 新鲜度：近 7 天是否已经发布过相近母题；相近则降权。

最终只输出：

1. 今日新增数、去重数、主库累计数。
2. 首选母题、对应原始热点、等级 S/A/B、推荐标题。
3. 两个备选标题及各自适用角度。
4. 一句选题理由和一条防重复提醒。

## 标题改造原则

- 保留热点的事实钩子，不照抄与账号无关的泛新闻表达。
- 优先改造成“熟龄处境 + 具体冲突 + 可执行判断”。
- 标题避免空泛的“人到晚年要明白”，尽量加入年龄、关系、钱、健康或场景。
- 政策和健康类内容必须保留日期、适用条件和信息来源，不把不确定信息写成确定结论。

## 防重复

检查最近已发布题目、同一母题最近 7 天的标题骨架，以及同一情绪表达是否连续出现。若重复，优先切换到不同人群、不同场景或不同解决方案，而不是只替换几个形容词。
